# Responsible use and scope note

This repository is an application portfolio and research training artifact. The included
results are produced on a transparent simulated benchmark. They must not be described as
results from PetroChina, Tarim Oilfield, a named electricity market, or a live trading
system.

The repository includes the configurations, output snapshots and tests needed to rerun
the experiment and inspect the failure cases. Any later use of employer or client data
would require written permission, de-identification and a separate data-governance
review.

Experiment dates and version-control history must remain factual. If a university,
supervisor or application form asks about generative AI, coding assistance or external
editing, that assistance should be disclosed accurately under the applicable rule.
